# dementia

## English

dementia is a self-hosted control panel for managing AmneziaWG VPN nodes, users, and subscriptions.

1. Start the backend. [Backend installation](https://github.com/dementia-panel/backend#english)
2. Start the web panel. [Panel installation](https://github.com/dementia-panel/panel#english)
3. Add a VPN server from the panel. [Node releases](https://github.com/dementia-panel/node/releases)

## Русский

dementia — панель для управления VPN-нодами AmneziaWG, пользователями и подписками на своём сервере.

1. Запусти backend. [Установка backend](https://github.com/dementia-panel/backend#русский)
2. Запусти веб-панель. [Установка панели](https://github.com/dementia-panel/panel#русский)
3. Добавь VPN-сервер через панель. [Релизы ноды](https://github.com/dementia-panel/node/releases)
